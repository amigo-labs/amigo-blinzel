# Photos in the screenshots

The pictures shown in the viewer are NASA images from the NASA Image and Video
Library (<https://images.nasa.gov>). NASA content is generally not copyrighted
and may be used for informational purposes; see NASA's media usage guidelines
(<https://www.nasa.gov/nasa-brand-center/images-and-media/>). NASA does not
endorse Blinzel.

The screenshots were taken from the Linux build on a virtual display (Xvfb,
software rendering), window about 1500 × 1000.
