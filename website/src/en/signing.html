Free code signing provided by SignPath.io, certificate by SignPath Foundation.

What is signed

Only the release files amigo-blinzel-setup-x64.exe and amigo-blinzel-setup-arm64.exe are signed. They are built exclusively by the release workflow on GitHub-hosted runners, from the public source code of this repository.

Roles

  • Committers and reviewers: the members of the amigo-labs organization on GitHub
  • Approval of every signature: an amigo-labs maintainer, manually in SignPath

Additional verification

The checksums of every release are also signed with the project's own Ed25519 key. The updater only installs files whose checksum, own signature and Authenticode signature all match.

Privacy

This program will not transfer any information to other networked systems, except for the update check with GitHub (see Privacy), which can be turned off.
