Installation

The downloaded file is viewer and installer in one. It installs for you only, to %LOCALAPPDATA%\Programs\amigo-blinzel, without administrator rights. To make amigo-blinzel the default for images, use Windows Settings; the setup opens the page if you like.

Uninstall: Settings → Apps → Installed apps.

Verify

The checksums are in SHA256SUMS, signed with the project's release key. On Windows: Get-FileHash amigo-blinzel-setup-x64.exe.

Updates

amigo-blinzel asks GitHub at most once a day whether there is a new version and installs it silently; it takes effect at the next start. To turn this off: auto_update = false in %APPDATA%\amigo-blinzel\settings.toml.
