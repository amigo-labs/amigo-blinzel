Windows

Windows 11 version 24H2 or newer.

x64 ARM64

The downloaded file is viewer and installer in one. It installs for you only, to %LOCALAPPDATA%\Programs\amigo-blinzel, without administrator rights. To make amigo-blinzel the default for images, use Windows Settings; the setup opens the page if you like. Uninstall: Settings → Apps → Installed apps.

First start: the file is not signed with a code signing certificate, so Windows SmartScreen shows “Windows protected your PC” at the first start: click More info, then Run anyway.

macOS

macOS 14 Sonoma or newer, Apple silicon and Intel in one app.

macOS (Universal)

The ZIP holds amigo-blinzel.app; drag the app into the Applications folder. Finder then offers it under “Open With” for images; make it the default through “Get Info” → “Open with” → “Change All”.

First start: the app is not notarized by Apple, so macOS reports at the first start that it cannot check it. On macOS 14: Control-click the app in Finder, choose Open and confirm. From macOS 15: open it once, then System Settings → Privacy & Security → Open Anyway. Or in Terminal: xattr -dr com.apple.quarantine /Applications/amigo-blinzel.app.

Linux

x64 and ARM64, Wayland or X11, with glibc 2.35 or newer (Ubuntu 22.04, Debian 12, Fedora 36 and later) and a Vulkan or OpenGL ES 3 driver.

x64 (.tar.gz) ARM64 (.tar.gz)

Unpack and install for you, without root:

tar xzf amigo-blinzel-linux-x64.tar.gz
./amigo-blinzel/blinzel --install

This puts the program in ~/.local/share/amigo-blinzel, a blinzel command in ~/.local/bin and an entry in the application menu with “Open with” for images. To make it the default image viewer: xdg-mime default amigo-blinzel.desktop image/jpeg image/png image/webp image/avif. Uninstall: blinzel --uninstall.

Verify

The checksums of all files are in SHA256SUMS, signed with the project's release key. On Windows: Get-FileHash amigo-blinzel-setup-x64.exe; on macOS and Linux: shasum -a 256 or sha256sum.

Updates

amigo-blinzel asks GitHub at most once a day whether there is a new version and installs it silently; it takes effect at the next start. This applies to the installed copy (on macOS: the app). To turn it off: auto_update = false in settings.toml, on Windows in %APPDATA%\amigo-blinzel, on macOS in ~/Library/Application Support/amigo-blinzel, on Linux in ~/.config/amigo-blinzel.
