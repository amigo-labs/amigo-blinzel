This website

The website sets no cookies, loads nothing from third parties and uses no analytics or tracking. It is served by Cloudflare, which processes technically necessary data such as the IP address to deliver the pages and protect them from abuse; Cloudflare's privacy policy applies.

Downloads come from GitHub (the project's releases); GitHub's privacy policy applies.

The application

amigo-blinzel collects no data and has no telemetry. Its only network connection is the update check: at most one request a day to the GitHub API, and for an update the download from GitHub. GitHub sees your IP address. The check can be turned off with auto_update = false.
