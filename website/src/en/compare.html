About amigo-blinzel

  • Source code: open on GitHub
  • Ads: none. Telemetry: none. Network: only the daily update check with GitHub, can be turned off.
  • Installation per user, no administrator rights: one executable on Windows, an app bundle on macOS, one file on Linux
  • Native for x64 and ARM64 or Apple silicon
