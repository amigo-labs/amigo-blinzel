Kostenlose Code-Signierung durch SignPath.io, Zertifikat der SignPath Foundation.

Was signiert wird

Signiert werden nur die Release-Dateien amigo-blinzel-setup-x64.exe und amigo-blinzel-setup-arm64.exe. Sie entstehen ausschließlich im Release-Workflow auf GitHub-gehosteten Runnern, aus dem öffentlichen Quellcode dieses Repositorys.

Rollen

  • Committer und Reviewer: die Mitglieder der Organisation amigo-labs auf GitHub
  • Freigabe jeder Signatur: ein Maintainer von amigo-labs, manuell in SignPath

Zusätzliche Prüfung

Die Prüfsummen jedes Release werden zusätzlich mit einem eigenen Ed25519-Schlüssel des Projekts signiert. Der Updater installiert nur Dateien, deren Prüfsumme, eigene Signatur und Authenticode-Signatur stimmen.

Datenschutz

Das Programm überträgt keine Daten an andere Systeme, außer bei der Update-Prüfung bei GitHub (siehe Datenschutz). Sie lässt sich abschalten.
