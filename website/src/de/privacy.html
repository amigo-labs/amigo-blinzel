Diese Website

Die Website setzt keine Cookies, lädt keine Inhalte von Dritten und verwendet keine Analyse- oder Tracking-Werkzeuge. Ausgeliefert wird sie von Cloudflare. Dabei verarbeitet Cloudflare technisch notwendige Daten wie die IP-Adresse, um die Seiten auszuliefern und vor Missbrauch zu schützen; es gilt die Datenschutzerklärung von Cloudflare.

Downloads kommen von GitHub (Releases des Projekts); dafür gilt die Datenschutzerklärung von GitHub.

Die Anwendung

amigo-blinzel sammelt keine Daten und hat keine Telemetrie. Die einzige Netzwerkverbindung ist die Update-Prüfung: höchstens einmal am Tag eine Anfrage an die GitHub-API, bei einem Update der Download von GitHub. Dabei sieht GitHub deine IP-Adresse. Die Prüfung lässt sich mit auto_update = false abschalten.
